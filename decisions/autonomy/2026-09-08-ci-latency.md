The owner authorized improvements to autonomous project workflows and explicitly requested that website text and presentation changes avoid unrelated contract and money-flow tests. This scope covers the CI classifier, conditional financial jobs, parallel execution and their control pins; it adds no financial, signing, broadcast or deployment authority.

Every candidate still receives universal clean-room, identity, append-only, secret and control checks and the real web build, tests and lint. The standalone clean-room scan remains; the duplicate repository scan inside its unit suite is removed while all rule fixtures remain. Cancellation can stop superseded runs.

A standalone classifier executes from the protected event base after a regular-blob and digest check. Only modifications of existing explicitly listed presentation files select the presentation path. Shared configuration, contracts, bots, dependencies, workflow changes, mixed paths, structural changes, manual requests and unknown paths receive full coverage. Invalid commit identities or inconsistent classifier bindings fail classification. A base predating both the classifier and its pin also receives full coverage.

The stable required statuses remain control-gate, identity-gate, gates and fork-proof. Their final aggregators reject missing, failed, cancelled or inconsistent applicable results. A skipped financial or archive suite is explicitly reported as NOT RUN; it is not a financial proof. Full-scope jobs preserve the existing financial suites and protected fork-proof commands. The automatic web job is part of gates so no GitHub ruleset change is needed; the standalone web workflow becomes manual-only to avoid duplicate automatic runs.

The v2 control-pin record binds the exact base and candidate control hashes under this existing owner authorization. Independent structural, executable and control-verifier checks must pass before the complete candidate is pushed and integrated under current green required CI. No historical approval or receipt is refreshed by this scope.
