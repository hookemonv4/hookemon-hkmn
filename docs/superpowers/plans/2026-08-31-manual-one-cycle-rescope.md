# Manual One-Cycle Phase 1 Rescope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce the Phase 1 release contract from twelve tasks to eleven by moving the dashboard to Phase 2 while preserving one capped manual cross-chain Collector cycle, exact net-USDG payout, and every immutable money and custody invariant.

**Architecture:** Requirements revision 55 and architecture revision 4 retain the onchain kernel and one linear offchain runner. The only removed Phase 1 capability is the dashboard; scheduling, continuous operation, catalog persistence, route optimization, multi-pack execution, and UI controls remain deferred. A narrow, owner-authorized ledger transition retires P1-011 without rewriting its attempt history and removes it from P1-012's dependencies.

**Tech Stack:** Node.js ESM and `node:test`, SQLite ledger, JSON v4 gates and receipts, Markdown ADR/module/task contracts, Foundry contracts, GitHub pull requests.
