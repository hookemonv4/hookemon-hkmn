The 250-USD ceiling still requires actual USDG acquisition pricing; deployment, seed/liquidity setup and approvals; Robinhood Arbitrum poster/L1 charges; refreshed bridge approval/deposit fees; Solana funding, Collector purchase and buyback costs; return bridge and final payout costs. Existing quote 25.298644 USDG is time-bound and already funded within the 150 USDG, so must not be counted again as new owner capital. For actual USD prices p per USDG and q per ETH, full native cost E and other dollar cost C, the necessary budget condition is 150p + Eq + C <= 250. Neither p=1 nor completion of this all-in bound is proven here.
