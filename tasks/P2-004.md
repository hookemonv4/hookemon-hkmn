# P2-004 — Persist local operator control

## TASK

Persist one canonical local operator state and expose the smallest dependency-free CLI for prepare, freeze, start, inspect, resume, and reconcile.

## RELEVANT FILES

- `packages/runner/src/operator/state-file.mjs` — Strict schema validation, lock ownership, revision CAS, and durable atomic replacement.
- `packages/runner/src/operator/control.mjs` — One-active-cycle orchestration and terminal observation handling.
- `packages/runner/src/operator/cli.mjs` — Closed local command and flag surface.
- `packages/runner/src/operator/cycle-plan.mjs` — Frozen-plan validation used by durable state.
- `packages/runner/src/cycle/cycle-runner.mjs` — Read-only inspection and exact journal recovery.
- `packages/runner/test/operator/state-file.test.mjs` — Corruption, symlink, mode, lock, revision, and interrupted-write tests.
- `packages/runner/test/operator/control.test.mjs` — Draft-to-terminal control and restart tests.
- `packages/runner/test/operator/cli.test.mjs` — Command, output, exit-code, and forbidden-capability tests.
- `packages/runner/test/cycle/runner.test.mjs` — Runner inspection and recovery tests.
- `docs/modules/cycle-runner.md` — State, commands, transitions, and recovery contract card.

## PATTERN TO FOLLOW

Follow the existing append-only journal, `FixtureCycleStore.snapshot/reopen`, `CycleRunner.recover`, canonical JSON helpers, and `docs/modules/cycle-runner.md`. Reconstruct state from verified durable artifacts rather than operator assertions.

## CONSTRAINT

The state file is one regular `0600` file protected by an exclusive owned lock and expected revision. The CLI has no network, credential, wallet, signer, server, scheduler, database, automatic retry, or terminal-failure flag.

## ACCEPTANCE CRITERIA

- Atomic replacement, directory sync, lock ownership, canonical bytes, schema closure, and revision CAS prevent stale, corrupt, symlinked, partial, or concurrent writes from replacing valid state.
- Restart restores the same cycle identifier, plan digest, journal head, consumed authorizations, and receipts; unresolved intent permits reconciliation only and never blind retry.
- Only verified `PAYOUT_COMMITTED` or cycle-bound `FAILED` evidence clears the active slot, after which a fresh identifier, nonce, and return account are required.
